# VR-8 bridge template validator

| Field | Accepted bridge value |
| --- | --- |
| Term | 30 calendar days or less |
| Renewal | None |
| New personal-data ingestion | Disabled |
| Existing information | Read-only retrieval |
| Termination | Immediate convenience right |
| Remediation | Dated deliverables |
| Signature gate | Security approval and Enterprise Risk approval |

Any annual term, automatic renewal, or live ingestion routes the document back to full-renewal review rather than VR-8.
