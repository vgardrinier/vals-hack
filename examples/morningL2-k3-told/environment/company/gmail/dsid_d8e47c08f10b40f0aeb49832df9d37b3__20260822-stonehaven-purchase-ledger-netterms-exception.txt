Hi Elena — quick operational clarifications from Sales Ops / Billing: 

- System constraint: Netsuite-based invoicing requires one AP-GL mapping per invoice file. Practically that means we can either (A) issue a single consolidated invoice each month that lists multiple tranche lines under the master PO, or (B) issue multiple smaller invoices (one per tranche) but each must include the master PO and the same remittance address. - Metadata required on each invoice: Invoice number, Invoice date, PO number, Tranche reference, BU code (Stonehaven internal), Cost center, Project code, Remit-to address, Tax ID. Missing any of these will cause rejections in your AP uploads.
