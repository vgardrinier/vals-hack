# QP-17 release matrix

| Record type | May close named finding | May replace operation-40 verification | ERP release authority |
| --- | --- | --- | --- |
| Customer concession | Yes, only listed finding and units | Only when verification is explicitly named | No |
| Technician completion | Rework execution only | No | No |
| Independent inspector signature | Safety-critical characteristic | Yes | Supports Quality release |
| Test-cell pass | Functional evidence | No | No |

The performer and independent inspector cannot be the same person for flight-control characteristics.
